# SONORA Music Website

A responsive dark-themed music **website** (not a native Android app) with the requested credit line at the very top:
- Founder: Shubh Arya
- Co-founder: Rushan Ahmad

Includes a homepage, music catalogue, search and mood filters, sample audio player, liked songs saved in this browser, and mobile-friendly layout.

## Publish using GitHub Pages on Android
1. Download and extract `sonora-music-website.zip`.
2. Open your GitHub repository in Chrome.
3. Tap **Add file → Upload files** and upload `index.html` to the repository root.
4. Commit the upload.
5. Open **Settings → Pages**.
6. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then tap **Save**.
7. Wait a few minutes and open the published URL shown on the Pages screen.

## Notes
This is a front-end website prototype. Liked songs are stored in local browser storage; there is no real user account system or server database yet. Sample audio URLs are demo audio and are not a commercial licensed music catalogue. Before a public streaming service launch, use music you have permission to stream and connect a secure backend/database.
